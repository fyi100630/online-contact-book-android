# 班級聯絡簿 Android（APK 反編譯版）

本倉庫包含從 Android APK 2.0.0 還原出的程式類別與資源，供閱讀、研究及後續重建參考。

## 專案狀態

這不是原始 Kotlin 專案。APK 反編譯後的程式以 Java 形式呈現，原始註解、完整 Compose 結構與建置設定無法由 APK 還原；目前也沒有 Gradle 專案檔，因此不能直接當作可建置的 Android Studio 專案。

為避免連線到原有外部服務，這份版本移除了遠端資料存取、更新下載及安裝統計傳送。資料儲存目前是佔位實作，不會保留新增或編輯的內容；更新功能也已停用。

## 功能畫面

APK 中可見的功能包含班級公告、作業、考試／評量、繳交項目、重要提醒，以及編輯介面。由於目前資料存取僅為佔位實作，這些畫面不代表完整功能都能運作。

## 目錄

- `app/src/main/java/`：反編譯後的 Java 類別
- `app/src/main/res/`：Android 資源
- `THIRD_PARTY_LICENSES/`：隨附第三方程式碼的授權文字
